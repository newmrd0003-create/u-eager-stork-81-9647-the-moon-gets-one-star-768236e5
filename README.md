## Entry

> One star. Reflected light, zero original content, and it still flooded my basement twice. Unfollowed.

101 characters, one line.

## Why this angle

The field is crowded with ghosting jokes ("ghosts me for a week every month") and night-shift gags ("works nights only, takes a month to finish one shift"). This entry takes a different angle: the Moon is famous for light it did not make, yet acts like the main character — and its one real job, the tides, flooded my basement twice. A rating, a grievance, and a reason the Moon earned its single star, with the punchline landing on "Unfollowed."

## How to run

```bash
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`). Validates first: single line, 1–120 characters.
